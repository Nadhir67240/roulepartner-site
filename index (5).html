Questions fréquentes

Qui peut utiliser RoulePartner ?

Les chauffeurs de taxi titulaires d'une licence. Nous démarrons dans le Bas-Rhin avant d'ouvrir à d'autres départements.

Est-ce que c'est vraiment gratuit ?

Oui. RoulePartner est entièrement gratuit, sans abonnement et sans engagement.

Faut-il télécharger une application ?

Non. RoulePartner s'ouvre directement dans le navigateur de votre téléphone. Vous pouvez l'ajouter à votre écran d'accueil comme une appli.

Que se passe-t-il si deux chauffeurs veulent la même course ?

Le premier qui accepte la récupère. La course disparaît aussitôt pour les autres : fini les doublons.

Les courses conventionnées sont-elles acceptées ?

Oui. Vous pouvez préciser le type de course (conventionnée, privée, gare, aéroport…) pour que le collègue sache à quoi s'attendre.

Prêt à ne plus perdre de courses ?

Rejoignez les chauffeurs du Bas-Rhin qui s'échangent déjà leurs courses.
